# calculadora-ajustes-
Criei essa calculadora usando HTML, CSS e JavaScript. Comecei a fazer esse projeto na faculdade, mas tive alguns problemas, pois os botões não funcionavam quando eu clicava. Por isso, continuei trabalhando nele em casa, fazendo alguns ajustes e corrigindo os erros para que tudo funcionasse corretamente. Com a ajuda de pesquisas e algumas informações da IA, consegui entender melhor os problemas e fazer as correções. Foi uma forma de praticar programação em casa e aprender um pouco mais sobre essas tecnologias.
